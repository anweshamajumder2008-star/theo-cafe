# 🌿 Theo Cafe - Digital Experience

A sanctuary of minimal aesthetic and botanical flavors.

## 🚀 Features
- **Botanical & Minimalist Aesthetics**: Tailored design system with custom colors and typography (`Libre Caslon Text` & `Plus Jakarta Sans`).
- **Interactive Navigation**: Scroll-spy active section underlining and animated mobile navigation drawer.
- **Mindful Menu & Specials**: Category-filtered menu items with interactive dish details preview.
- **Vercel Ready**: Preconfigured for seamless deployment on Vercel.

## 💻 Local Development

Run the local development server:

```bash
npm run dev
```

Open `http://localhost:3000` in your browser.

## ☁️ Deploying to Vercel

1. Import this repository in [Vercel](https://vercel.com).
2. Framework Preset: **Other** / **Static Site**.
3. Click **Deploy**.
